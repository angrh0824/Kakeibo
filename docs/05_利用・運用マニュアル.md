# 家計簿 Ver2.0 利用・運用マニュアル

最終更新: 2026-11-05

この文書は、家族・友人が家計簿アプリを使う手順と、管理者が利用者・料金・データを管理する手順をまとめたものです。現在の技術仕様は`00_現行実装仕様.md`を優先してください。

## 1. アプリを開く

公開URL:

- https://angrh0824.github.io/Kakeibo/

推奨環境:

- Android: 最新版Google Chrome
- iPhone / iPad: 最新版SafariまたはChrome
- PC: 最新版Chrome、Edge、Safari

GitHub PagesのURL自体は公開されていますが、家計簿データ、レシート画像、解析APIはGoogleログインと家計簿メンバー権限がなければ利用できません。

## 2. 初回ログイン

1. アプリを開きます。
2. 「Googleでログイン」を押し、使いたいGoogleアカウントを選びます。
3. 初回は利用申請が自動作成され、管理者の承認待ちになります。
4. 管理者が承認した後、ページを再読み込みしてもう一度ログインします。
5. 承認されたアカウントには、本人がオーナーの個人家計簿が1つ自動作成されます。

Googleアカウントとして登録済みなら、メールアドレスの末尾は`gmail.com`でなくても利用できます。

### ログインできない場合

- 「承認待ち」: 管理者の承認を待ってください。
- 「このアカウントでは利用できません」: BAN、未承認、または認証期限切れの可能性があります。
- Googleボタンが表示されない: 通信状態を確認し、ページを再読み込みしてください。
- 古い画面が出る: ブラウザの再読み込みを行い、改善しなければ一度タブを閉じて開き直してください。

## 3. 画面の基本操作

スマートフォンでは画面下のタブで移動します。

- ホーム: 今月の支出、予算の残り、カテゴリ別、支出のペース、値動き
- 履歴: 日ごとの記録の一覧と検索
- 中央の「＋」: 記録の方法を選ぶ（レシートを撮影・写真から読み取る・手入力）
- 分析: 月ごとの推移、よく行くお店、品目ごとの価格
- 設定: 予算、カテゴリ、固定費、表示、メンバー、料金、データ

PCとタブレットでは左側のメニューに同じ項目と「レシートを読み取る」「手入力で記録」ボタンが並びます。

記録を押すと、下から詳細のシートが開きます。シートの外を押すか、右上の閉じるボタン、PCではEscキーで閉じます。

Android PixelとiPhoneのブラウザ表示領域に合わせ、レシート確認画面の操作ボタンは端末下部のシステムバーより上へ残る設計です。ログイン画面もPixelのアプリ内ブラウザや表示・非表示が変わるツールバーを考慮し、現在見えている領域の中央へ自動調整します。

表示は端末のライト・ダーク設定に自動で合わせます。「設定」→「表示」でライトまたはダークに固定することもできます。この設定は端末ごとです。

## 4. 表示月を変更する

画面上部の`<`と`>`で対象月を変更します。月の名前を押すと今月に戻ります。

対象月を変更すると、ホーム・履歴・分析が同じ月へ切り替わります。

## 5. レシートを読み取る

### 基本手順

1. スマートフォンは画面下中央の「＋」から「レシートを撮影」または「写真から読み取る」を、PCは左のメニューの「レシートを読み取る」を押します。
2. 確認画面が開いたら、必要に応じて「カメラで撮影」または「写真から選ぶ」で画像を追加します。
3. 撮影・選択した画像は一覧へ追加されます。この時点では解析を開始しません。
4. 必要に応じて「続けて撮影」または「写真を追加」を押し、合計10枚まで追加します。不要な画像は`×`、全削除は「すべて外す」で取り除けます。
5. 内容がそろったら「選択した画像をまとめて解析」を押します。
6. AI解析が終わるまで画面を閉じずに待ちます。
7. 店舗、日付、信頼度、購入品目、合計を確認します。
8. 必要な箇所を修正します。
9. 「承認して登録」を押します。

承認したレシートだけが選択中の家計簿へ登録されます。

### 選択できる画像

- 一度に最大10枚
- 1ファイル最大15MB
- 1枚の写真に複数のレシートが写っていても解析可能
- 写真ライブラリでは複数枚を一度に選択可能
- カメラ撮影と写真ライブラリの画像を同じ解析へ混在可能
- 画像はサーバーで向き補正・縮小・JPEG圧縮してからAI解析と非公開保存を実施

複数レシートを検出した場合、確認画面に`1 / 3件目`のように表示されます。1件承認すると次のレシートへ進みます。

### 解析中の3表示

1. 「画像を送信」: 画像をCloud Runの解析APIへ送っています。
2. 「AI一括解析」: AIが文字認識、品目抽出、金額補正、カテゴリ分類をまとめて行っています。
3. 「結果を準備」: 受信済み結果を確認画面へ整えています。

独立したOCR、構造化、カテゴリ分類を3回呼んでいるわけではありません。通常は2番目が最も長く、レシートの品目数、画像品質、AIサービスの混雑、通信速度によって時間が変わります。2026-08-13の実機確認ではCloud Run全体で約4.7秒でしたが、長いレシートではそれ以上かかることがあります。

### 読み取りやすい撮影方法

- レシート全体を画面内へ入れる
- 真上から撮り、台形の歪みを減らす
- 影、指、反射、折れ目を避ける
- 文字へピントを合わせる
- 暗い場所では明るい机へ移動する
- 複数レシートは重ねず、間隔を空ける
- 20品目以上の長いレシートは、文字が読める解像度を保つ
- 小さく写りすぎる場合は、レシートごとに撮影する

## 6. AI解析結果を確認・修正する

確認画面には、読み取りに使った元のレシート画像が品目と並んで表示されます。スマートフォンでは画像が上に出て、タップすると拡大、ピンチやダブルタップでズームできます。品目の合計がレシート記載の合計と違う場合は、差額が表示されます。

確認できる項目:

- 店舗名
- 購入日
- 信頼度
- 品名
- 単価
- 数量
- カテゴリ
- 小計
- 合計金額

モバイルでは各品目カード内で編集し、本文だけを縦にスクロールします。「破棄する」「承認して登録」は画面下部に残ります。

### 品目を直す

- 品名、単価、数量は入力欄を直接変更します。
- カテゴリは選択欄から変更します。
- 「＋ 品目を追加」で行を追加します。
- 品目右上の`✕`で不要な行を削除します。
- 単価または数量を変えると、その品目の小計と全体合計を再計算します。

AIは外税、内税、割引、端数を明細へ配分し、印字合計と合うように結果を作ります。単価を手動変更するとその行は`単価 × 数量`で再計算されるため、最後にレシート画像の印字合計と一致するか確認してください。

### 承認と破棄

- 「承認して登録」: 選択中の家計簿へ保存します。
- 新規解析時の「破棄する」: 未承認の解析結果を登録せず閉じます。
- 既存レシート編集時の「破棄する」: 確認ダイアログ後、その保存済みレシートを家計簿Dataから削除します。

## 7. ホーム

対象月について次を表示します。

- 使ったお金: 今日までの支出の合計。先月の同じ日までとの差も表示します。
- 予算のバー: 使った額、これから引き落とされる固定費の予定（斜線）、今日までの目安（縦線）を1本で示します。
- 使える残り・1日あたり: 予算から、使った額と固定費の予定を引いた残りと、残りの日数で割った目安です。
- 月末の見込み: 固定費以外の支出を今日までのペースで延ばした見込みです。
- まだ記録していない固定費: 電気代のように毎月金額が変わる固定費が未記録なら、ここから記録できます。
- カテゴリ別: 予算に対する使った額。予算を超えたカテゴリには警告と超えた額が出ます。押すとそのカテゴリの履歴を開きます。
- 支出のペース: 今月と先月の累計、予算の目安を日ごとの折れ線で比べます。
- よく買う品の値動き: 2回以上買った品目のうち、最後の価格がそれまでの平均から3%以上変わったものです。
- 最近の記録

予算が未設定のときは「予算を決める」ボタンが出ます。

## 8. 履歴

対象月の記録を新しい順に、日ごとの合計と一緒に表示します。月の合計には、まだ日付が来ていない固定費の予定を含めず、「このあと予定」として別に表示します。予定は一覧の一番下にまとまります。

- 検索: 店名、品名、メモのどれでも探せます。
- カテゴリの絞り込み: そのカテゴリの金額だけを合計します。
- 種類の絞り込み: すべて、レシート、手入力、固定費、要確認

記録を押すと詳細が開きます。

- レシート: 金額、カテゴリの内訳、品目、保存画像。画像を押すと拡大表示します。品名を押すとその品の価格の詳細へ移ります。
- 手入力: 金額、カテゴリ、メモ
- 固定費の予定: 「今月の金額を記録」で実際の金額に置き換えられます。

詳細の「編集」で修正、「削除」で記録を削除します。削除は家計簿のメンバー全員に反映されます。

### 保存画像

新しく解析した画像は非公開Cloud Storageへ保存されます。詳細を開くと、選択中の家計簿メンバーであることをAPIが確認してから表示します。

古いデータや画像保存開始前のレシートは「この記録には保存された画像がありません」と表示される場合があります。

## 9. 手入力・固定費・予算・カテゴリ

### 手入力で記録する

レシートが出ない支出（現金払い、家賃、サブスク、ネットの買い物など）は手入力します。

1. 「＋」→「手入力」、またはPCの「手入力で記録」を押します。
2. 金額を入力し、カテゴリを選びます。全角数字でも入力できます。
3. 必要なら内容、日付、お店・支払先、メモを入れて「記録する」を押します。

「毎月の固定費にする」をオンにすると、その記録を今月分として、来月以降は同じ金額で自動計上します。

### 固定費を登録する

「設定」→「固定費」→「追加」で、名前、金額、カテゴリ、支払日、開始月、終了月を登録します。

- 金額を入れた固定費は、毎月の支払日に自動で計上されます。実際に記録をつける必要はありません。
- 金額を空欄にした固定費（電気代など）は、ホームの「まだ記録していない固定費」から毎月の金額を記録します。
- 金額が違った月は、履歴でその固定費を開き「今月の金額を記録」で実際の金額に置き換えます。
- 解約したら終了月を入れてください。削除すると、過去に自動計上していた分も表示されなくなります。

### 予算を決める

「設定」→「予算」で、月の予算とカテゴリごとの予算を入れて「予算を保存」を押します。月の予算を空欄にすると、カテゴリ予算の合計を月の予算として使います。予算は家計簿のメンバー全員で共有されます。

### カテゴリを編集する

「設定」→「カテゴリ」で次の操作ができます。

- 追加: 名前と色を選びます。
- 名前の変更: これまでの記録の品目もまとめて新しい名前に変わります。
- 削除: 移動先のカテゴリを選ぶと、品目と予算をそこへ移します。
- 色: 見分けやすさを検証した9色から選べます。グラフでは名前も必ず一緒に表示します。

「その他」は読み取りの受け皿として常に残ります。AIのレシート読み取りは、この家計簿のカテゴリの中から分類します。

## 10. 分析

### 支出の推移

- 今月の支出、月末の見込み、それまでの平均（過去の月を表示中は、平均との差と予算との差）
- 月ごとの支出: カテゴリ別の積み上げ棒グラフ。6か月と12か月を切り替えられます。棒を押すとその月へ移ります。「表で見る」で同じ数字を表で確認できます。
- よく行くお店: 対象月の店ごとの合計、回数、1回あたりの金額

### 品目と価格

レシートの品目から自動で集計します。

- よく買う品の価格: 2回以上買った品について、最後の価格とそれまでの平均を、使った金額で重み付けして比べた変化率
- 値上がり・値下がりした品の数
- 品目の一覧: 検索、カテゴリの絞り込み、並び替え（よく買う順、値上がり順、使った金額順、最近買った順）

品目を押すと、最後の価格、平均・最安・最高、購入ごとの価格の折れ線、購入履歴が出ます。「品名・カテゴリを編集」で名前やカテゴリを直せます。すでにある品名にすると、同じ品としてまとめて集計します（表記ゆれの統合）。変更は選択中の家計簿の記録だけに反映され、他の家計簿には影響しません。

## 11. 家計簿を切り替える・共有する

「設定」→「家計簿とメンバー」を開きます。

### 家計簿を切り替える

「表示する家計簿」で参加中の家計簿を選びます。切替後は、レシート、商品マスタ、グラフ、画像、料金がすべて選択先へ切り替わります。

### 家族や友人を招待する

家計簿オーナーだけが招待できます。

1. 「Googleアカウントのメールアドレス」へ招待先を入力します。
2. 「招待する」を押します。
3. 招待先が承認済み利用者なら、すぐに家計簿へ追加されます。
4. 未利用者なら、本人が初回ログインし、プラットフォーム管理者が承認した後に追加されます。

招待メールは自動送信しません。URLと利用手順は別途本人へ伝えてください。

オーナーはメンバー一覧からメンバー解除や未完了招待の取消ができます。

## 12. 月別利用料金と累積未精算残高

家計簿オーナーには「設定」内に料金画面が表示されます。

確認できる内容:

- AI / OpenRouter実費
- Cloud Run概算
- Firestore概算
- 画像ストレージ概算
- 概算原価
- 運営協力分
- 任意精算の目安
- これまでの利用料金合計
- 累積未精算残高
- 累積利用上限と残り金額
- 利用トークン、解析回数などの利用量

Cloud分は無料枠適用前の保守的な概算です。OpenRouter分はAPI応答に含まれる実費です。現在の任意精算目安は`概算原価 + 運営協力分100%`を1円単位へ切り上げた値です。

月別料金は日本時間の月ごとに履歴として残り、過去月も選択して確認できます。月が変わっても料金履歴は消えません。未精算の任意精算目安は翌月へ繰り越され、「累積未精算残高」へ加算されます。

PayPay QRが表示されても自動決済、強制請求、入金確認は行いません。友人間で合意した任意精算用です。

累積未精算残高が累積利用上限へ達すると、新しいレシート解析だけが`429`で止まります。既存データの閲覧、編集、削除、バックアップは引き続き可能です。

## 13. データ同期とバックアップ

「設定」→「データ」で操作します。

- 「表計算用に書き出す（CSV）」: すべての記録を品目ごとの行でCSVに書き出します。ExcelやGoogleスプレッドシートでそのまま開けます。
- 「バックアップ（JSON）」: 選択中の家計簿の記録と設定をJSONファイルとして端末へ保存します。
- 「今すぐ同期」: Firestoreの最新データを読み直します。

現在はJSONからの自動復元機能がありません。バックアップファイルは削除せず、安全な場所へ保管してください。

アプリの正本はFirestoreとCloud Storageです。コード更新、GitHub Pagesの再公開、端末変更、ブラウザキャッシュ削除では保存済み家計簿データは消えません。

サーバーが予算・カテゴリ・固定費の保存に未対応の古い版のときは、画面上部に「この端末だけに保存されます」と表示し、設定をその端末に保存して動作を続けます。

## 14. 管理者向け操作

プラットフォーム管理者だけに、設定画面の管理カードが表示されます。

### 初回利用を承認する

1. 設定メニューの件数バッジ、アプリ内通知、またはGoogle Cloud Monitoringの通知を確認します。
2. 「利用申請とアカウント管理」→「承認待ち」を開きます。
3. 対象アカウントを確認して承認します。

承認すると本人の個人家計簿を作り、事前招待があれば招待先家計簿にも追加します。

### BAN・解除

- BANすると、対象利用者は次のAPI操作からデータ、画像、解析を利用できません。
- BAN解除で再び利用可能になります。
- 管理者自身はBANできません。

### 全家計簿の料金・残高・利用上限

管理者は対象月ごとに次を確認・変更できます。

- 選択月の全家計簿の概算原価と任意精算目安
- 全家計簿の累積未精算残高
- 家計簿ごとの月別内訳
- 家計簿ごとの累積利用上限
- 家計簿ごとの未精算残高
- 家計簿オーナーへ表示するPayPay QR

PayPay QR画像は非公開Cloud Storageへ保存され、家計簿オーナーだけが認証済みAPI経由で取得します。

「設定を保存」で累積利用上限と未精算残高を任意額へ変更できます。「0円にする」は支払い確認または管理者による免除として、残高だけを0円にします。どちらもプラットフォーム管理者だけが操作できます。

0円にしても月別料金履歴は残り、その後の利用料金は再び残高へ加算されます。累積利用上限を0円に設定した場合は「上限なし」です。

## 15. AIモデルについて

誤解を招いていた未接続の「AI解析設定」カードは削除しました。利用者や家計簿オーナーが画面からモデルを変更することはできません。

本番モデルはCloud Run環境変数で管理し、現在は次です。

- `google/gemini-2.5-flash-lite`

画像はこのモデルへ直接入力します。Google Vision APIやTesseractを独立した前段OCRとして通常フローで呼び出していません。

## 16. よくある問題

### AI解析が長い

AI一括解析は外部AIサービスの応答待ちが中心です。長いレシート、暗い画像、複数画像では時間が増えます。

- 通信状態を確認する
- 解析中に画面を閉じない
- 2分以上変化がなければ一度閉じ、画像を1枚ずつ再試行する
- 長いレシートは文字が大きく写るよう撮り直す

Cloud Runは現在1 vCPU / 512 MiBですが、直近の実測ではCloud Run全体で約4.7秒でした。CPUを2倍にしても外部AIの応答待ちはほぼ短縮されないため、現状は増強していません。

### 承認ボタンが下へ隠れる

2026-08-13にPixel向け修正を反映済みです。古い表示が残る場合はページを再読み込みしてください。それでも隠れる場合は次を記録して管理者へ伝えてください。

- 端末名
- OSバージョン
- ブラウザ名とバージョン
- 縦画面か横画面か
- スクリーンショット

### 履歴にデータがない

- 上部の対象月を確認する
- 検索欄を空にする
- 種類の絞り込みを「すべて」、カテゴリを「すべてのカテゴリ」に戻す
- 設定で正しい家計簿が選ばれているか確認する
- 「今すぐ同期」を押す

### 合計がレシートと違う

- 税、割引、ポイント利用、値引き行を確認する
- 品目の単価、数量、小計を修正する
- 不要行を削除し、足りない行を追加する
- 最後に印字合計と画面合計が一致することを確認して承認する

### 画像が見えない

- 画像保存開始前の古いレシートには画像がない場合があります。
- 家計簿を切り替えた直後なら再同期してください。
- ログイン期限切れなら再ログインしてください。

### `401`、`403`、`429`

- `401`: ログイン期限切れ。再ログインしてください。
- `403`: 未承認、BAN、または選択中の家計簿メンバーではありません。
- `429`: 家計簿の累積未精算残高が累積利用上限へ達しています。管理者へ確認してください。

## 17. セキュリティとデータの所在

- 画面とコード: GitHub Pages
- API: Google Cloud Run
- レシート・家計簿データ: Firestore
- レシート画像: 非公開Cloud Storage
- AI解析: Cloud RunからOpenRouter
- APIキー: Secret ManagerからCloud Runだけへ渡す
- ログイン: Google Identity Services

OpenRouter APIキーはGitHubにもブラウザにも保存しません。Google IDトークンはブラウザのセッション中だけ保持します。すべての家計簿APIは選択中の家計簿IDとメンバー権限を照合します。

## 18. 現在の主な制限

- 招待メールを自動送信しない
- JSONバックアップからの自動復元は未実装
- データ更新のリアルタイムPushは未実装
- 承認せず破棄した解析画像の自動定期削除は未実装
- 品目の表記ゆれは手動の統合のみ（自動の名寄せは未実装）
- 銀行・カードの明細の自動取り込みは未実装（手入力と固定費で補う）
